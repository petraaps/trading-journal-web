# PeTrade Journey

Digunakan untuk mencatat dan mengevaluasi aktivitas trading pribadi saya yang sudah dilakukan.

## Fitur

Website Trading Journal memiliki beberapa fitur utama:

- Melihat ringkasan akun trading.
- Melihat performa trading.
- Melihat riwayat trading.
- Menambahkan data trade.
- Melihat detail trade.
- Menyimpan reason entry.
- Menampilkan gambar analisa trading.
- Mengatur informasi akun trading.

## Halaman Website

Website terdiri dari 4 halaman utama:

1. `index.html` - Dashboard dan riwayat trading.
2. `akun.html` - Informasi dan pengaturan akun trading.
3. `tambah-trade.html` - Form untuk menambahkan data trade.
4. `detail-trade.html` - Menampilkan informasi lengkap dari sebuah trade.
